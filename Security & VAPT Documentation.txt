## ?? Security Implementation Files

### Security/SecurityHeadersMiddleware.cs
Implements HTTP security headers:
- X-Frame-Options (Clickjacking protection)
- Content-Security-Policy
- X-Content-Type-Options (MIME sniffing protection)
- Strict-Transport-Security (HSTS)
- X-XSS-Protection

### Security/RateLimitingConfiguration.cs
Implements API rate limiting:
- IP-based rate limiting
- Endpoint-specific limits
- Authentication endpoint protection (5 attempts/minute)
- Advanced user-based tracking

### Security/InputValidationAttributes.cs
Custom validation attributes:
- `[SanitizeInput]` - XSS and SQL injection prevention
- `[StrictEmail]` - Email format validation
- `[ValidObjectId]` - MongoDB ID validation
- `[SafeFilePath]` - Path traversal prevention
- `[SafeUrl]` - SSRF attack prevention
- `[StrongPassword]` - Password complexity enforcement

### Security/SecurityAuditLoggingMiddleware.cs
Comprehensive audit logging:
- Request/response logging
- Authentication attempt tracking
- Security threat detection
- Sensitive data sanitization
- Anomaly detection

## ?? Quick Start Implementation

### Step 1: Install Required Packages
```bash
cd TeamTamApi
dotnet add package AspNetCoreRateLimit
dotnet add package Microsoft.Extensions.Caching.StackExchangeRedis
```

### Step 2: Update Program.cs
```csharp
using TeamTamApi.Security;

// Add rate limiting configuration
AuthenticationRateLimitConfiguration.ConfigureRateLimiting(builder.Services, configuration);

var app = builder.Build();

// Add security middleware (in order)
app.UseSecurityHeaders();
app.UseSecurityAuditLogging();
app.UseHttpsRedirection();
app.UseIpRateLimiting();
app.UseMiddleware<AdvancedRateLimitingMiddleware>();
app.UseAuthentication();
app.UseAuthorization();
```

### Step 3: Fix Critical Issues
1. **Remove hardcoded credentials from appsettings.json**
   ```bash
   # Move to Azure Key Vault or environment variables
   # Rotate all exposed credentials immediately
   ```

2. **Add authorization to stealth endpoints**
   ```csharp
   [Authorize(Roles = RoleConstant.SuperAdmin_Role)]
   public async Task<LoginConfigResponse> StealthLoginByEmail(string email)
   ```

3. **Enable HTTPS metadata validation**
   ```csharp
   x.RequireHttpsMetadata = !builder.Environment.IsDevelopment();
   ```

### Step 4: Add Input Validation to DTOs
```csharp
using TeamTamApi.Security;

public class LoginRequest
{
    [Required]
    [StrictEmail]
    [SanitizeInput]
    public string Email { get; set; }

    [Required]
    [StrongPassword(minLength: 12)]
    public string Password { get; set; }
}
```

## ?? Testing the Security Implementation

### Manual Testing
```bash
# Test security headers
curl -I https://api.teamtam.com/api/v1/Login

# Test rate limiting
for i in {1..10}; do
  curl -X POST http://localhost:5000/api/v1/Login/LoginWithDomain \
    -d '{"email":"test@test.com","password":"test"}'
done

# Test input validation
curl -X POST http://localhost:5000/api/v1/Login \
  -d '{"email":"<script>alert(1)</script>"}'
```

### Automated Testing
```bash
# OWASP ZAP baseline scan
docker run -t owasp/zap2docker-stable zap-baseline.py \
  -t http://localhost:5000/api/v1

# Dependency vulnerability check
dotnet list package --vulnerable

# Run Nikto scanner
nikto -h http://localhost:5000
```
